# PROJECT_UNITY · Grand Archives public preview

GitHub Pages: https://shishiba389.github.io/PROJECT_UNITY/

This repository contains a static export of `D:/PROJECT_UNITY/ANT`, built with `python build_pages.py` from the local Grand Archives source (the ANT repository). The `project-m2` image editor and the `pallet-3d` pallet calculator are included. Brand library, search, and master data use demo content.

Auto Fill (PROJECT_AUTO) and Price update (PriceSync, UPDATE_PRICE_TOOL) are private and not published here. Run Grand Archives locally with `run-ant.bat` (or `python serve.py`) from the ANT source directory, then open this site with `?local=1`: live search and those two tools then come from the local server.
