# PROJECT_UNITY · A.N.T public preview

GitHub Pages: https://shishiba389.github.io/PROJECT_UNITY/

This repository contains a static export of `D:/PROJECT_UNITY/ANT`, built with `python build_pages.py` from the local A.N.T source. The `project-m2` image editor is included. Brand library, search, and master data use demo content.

Auto Fill (PROJECT_AUTO) and Price update (PriceSync, UPDATE_PRICE_TOOL) are private and not published here. Run A.N.T locally with `run-ant.bat` (or `python serve.py`) from the A.N.T source directory, then open this site with `?local=1`: live search and those two tools then come from the local server.
